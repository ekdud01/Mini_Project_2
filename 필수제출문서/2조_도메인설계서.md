## 1. 프로젝트 개요

### 1.1 프로젝트 목적

사용자가 언제 어디서나 간편하게 KDSQ(한국형 치매선별설문지) 기반의 인지기능 자가검진을 진행할 수 있도록 하고, 검사 결과 데이터 조회 및 고위험군 여부 판정 과정을 디지털화하여 치매 조기 진단 및 관리의 효율성을 높인다. 또한, 개인별 시계열 검사 추이 확인 및 통계적 비교 정보를 제공한다.

### 1.2 프로젝트 범위

**포함 범위:**
- 회원 관리 — 일반 이메일 기반 가입, 로그인(JWT), 인구학적 정보(출생년도/연령, 성별, 학력 등) 관리  
- 설문 및 검사 관리 — KDSQ-P(5문항 1차 검사) 및 KDSQ-C(15문항 2차 상세 검사) 문항 데이터 및 응시 관리  
- 검사 결과 및 통계 관리 — 점수 자동 산출, 정상/고위험군 분류, 개인별 시계열 결과 추이 조회, 전체 사용자 평균치/이상치 비교 통계 제공  
- 맞춤 솔루션 제공 — 검사 결과 고위험군 판정 시 유용한 정보 및 솔루션 안내

**제외 범위:**
- 결제 시스템  
- 실시간 알림 (이메일 알림 등)  
- 병원 연계 예약 시스템

### 1.3 주요 이해관계자

| 구분 | 역할 | 주요 관심사 |
|------|------|-------------|
| **일반 사용자 (검사 대상)** | 시스템 사용자 | 간편 인지 검사 응시, 개인 검사 결과 및 시계열 추이 조회, 전체 통계 비교 |
| **사이트 관리자 (Admin)** | 사이트 관리자 | 수집된 검사 데이터 검수, 데이터 다운로드/추출, 플랫폼 운영 관리 |
| **IT 담당자** | 시스템 관리자 | 서버 운영, 보안, 백업, 확장성 |

## 2. 비즈니스 도메인 분석

### 2.1 핵심 비즈니스 프로세스

#### 2.1.1 인지선별검사 및 결과 판정 프로세스
```
[사용자] 로그인 후 KDSQ-P (5문항) 검사 응시
    ↓
[시스템] 점수 자동 산출 (4점 기준 판정)
├─ [4점 미만] → 정상 판정, 결과 저장 및 통계 반영
└─ [4점 이상] → KDSQ-C (15문항) 추가 상세 검사 진행
    ↓
[시스템] 15문항 영역별 점수 산출 및 판정 기준 적용
├─ [0 ~ 5점]  → 특이소견 없음 (정상)
└─ [6 ~ 30점] → 인지기능 저하 의심 (고위험군 / 치매 의심)
    ↓
[시스템] 결과 저장 및 맞춤 솔루션(정보) 제공
```

**비즈니스 규칙:**
- KDSQ-P(5문항) 점수가 4점 이상인 경우에만 KDSQ-C(15문항) 추가 검사 진행  
- KDSQ-C(15문항): 점수 0\~5점 (특이소견 없음 / 정상), 6\~30점 (인지기능 저하 의심 / 고위험군)
- 검사 결과는 사용자 계정에 영구 저장되어 마이페이지에서 시계열 그래프로 추이 확인 가능  
- 통계 페이지를 통해 전체 사용자 평균치와 비교하여 자신의 위치(이상치/평균치 근접 여부) 확인 가능

#### 2.1.2 회원 가입 / 로그인 프로세스
```
[사용자] 이메일 + 비밀번호 + 인구학적 정보(성별 등) 입력
    ↓
[시스템] 이메일 중복 확인 → 비밀번호 BCrypt 암호화
    ↓
[사용자] 로그인 → JWT 액세스 토큰 + 리프레시 토큰 발급
```

### 2.2 비즈니스 이벤트

| 이벤트 | 트리거 | 결과 |
|--------|--------|------|
| **회원 가입** | 정보 입력 후 가입 버튼 | Member 레코드 생성, 비밀번호 암호화 저장 |
| **로그인 성공** | 이메일/비밀번호 일치 | JWT 액세스·리프레시 토큰 발급 |
| **KDSQ-P 검사 완료** | 5문항 제출 | ExamResult 생성, 점수 산출 (4점 기준 분기) |
| **KDSQ-C 검사 완료** | 15문항 추가 제출 | 상세 ExamResult 업데이트 및 고위험군 판정 (6점 기준 분기), 맞춤 솔루션 매핑 |
| **회원 탈퇴** | 탈퇴 요청 | Member status: ACTIVE → WITHDRAWN |

## 3. 핵심 도메인 객체

### 3.1 도메인 객체 식별 매트릭스

| 도메인 객체 | 유형 | 중요도 | 복잡도 | 연관관계 수 | 우선순위 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Member** (회원) | Entity | 높음 | 중간 | 1개 (ExamResult) | 1순위 |
| **Survey** (설문지) | Entity | 높음 | 낮음 | 1개 (Question) | 1순위 |
| **Question** (문항) | Entity | 높음 | 중간 | 2개 (Survey, Option) | 1순위 |
| **ExamResult** (검사결과) | Entity | 높음 | 높음 | 2개 (Member, Survey) | 1순위 |
| **Solution** (솔루션 안내) | Entity | 낮음 | 낮음 | 1개 (ExamResult) | 2순위 |
| **Gender** | Enum | 중간 | 낮음 | — | 2순위 |
| **ExamType** | Enum | 중간 | 낮음 | — | 2순위 |
| **RiskLevel** | Enum | 중간 | 낮음 | — | 2순위 |

### 3.2 상세 도메인 객체 정의

#### 3.2.1 Member (회원)

**역할:** 플랫폼을 이용하며 인지선별검사를 수행하는 일반 사용자

**주요 속성:**
- `id`: 회원 고유 PK  
- `email`: 이메일 (로그인 ID 겸용, 유일값)  
- `password`: BCrypt 암호화된 비밀번호  
- `gender`: 성별 (Gender Enum: MALE, FEMALE)  
- `birthYear`: 출생년도 (연령대 통계 산출용)  
- `educationLevel`: 학력 정보  
- `status`: 회원 상태 (UserStatus Enum)

**주요 행동 (메서드):**
- `updateProfile()`: 프로필 정보 수정  
- `withdraw()`: 회원 탈퇴 처리 → WITHDRAWN

**비즈니스 규칙:**
- 이메일은 유일(UNIQUE)해야 하며 로그인 ID로 사용  
- 탈퇴한 회원은 재로그인 불가

#### 3.2.2 Survey (설문지) 및 Question (문항)

**역할:** KDSQ-P 및 KDSQ-C 검사의 문항 및 구조 정의

**주요 속성 (Survey):**
- `id`: 설문지 PK  
- `examType`: 검사 유형 (ExamType Enum: KDSQ_P, KDSQ_C)  
- `title`: 설문지 제목  
- `description`: 설문 설명

**주요 속성 (Question):**
- `id`: 문항 PK
- `surveyId`: 소속 설문지 FK 
- `questionNumber`: 문항 번호
- `content`: 문항 내용
- `score`: 문항별 배점

#### 3.2.3 ExamResult (검사결과)

**역할:** 사용자가 수행한 검사 응시 이력 및 결과 데이터

**주요 속성:**
- `id`: 결과 PK  
- `memberId`: 회원 FK  
- `examType`: 검사 유형 (KDSQ_P, KDSQ_C)  
- `memoryScore`: 기억력 영역 점수 (KDSQ-M, 1~5번 문항 합산)
- `otherScore`: 기타 인지기능 영역 점수 (KDSQ-O, 6~10번 문항 합산)
- `adlScore`: 일상생활수행능력 영역 점수 (KDSQ-A, 11~15번 문항 합산)
- `totalScore`: 총 획득 점수 (영역별 점수 합산)  
- `riskLevel`: 판정 등급 (RiskLevel Enum: NORMAL, HIGH_RISK, DEMENTIA_SUSPECTED)  
- `createdAt`: 검사 일시 (시계열 추이 분석용)

**주요 행동 (메서드):**
- `calculateScore()`: 영역별 문항 점수 분할 합산 
- `evaluateRisk()`: 점수 기준(KDSQ-C 기준 0~5점 정상, 6~30점 고위험군)에 따른 위험도 판정

**비즈니스 규칙:**
- KDSQ-P 검사 결과 점수가 4점 이상일 경우 KDSQ-C(15문항) 추가 검사 진행  
- KDSQ-C 판정 기준: 0\~5점 (특이소견 없음 / 정상), 6\~30점 (인지기능 저하 의심 / 고위험군)  
- 검사 결과는 영역별 세부 점수와 함께 날짜별로 누적 저장되어 마이페이지 시계열 그래프 데이터로 활용

#### 3.2.4 Solution (솔루션 안내)

**역할:** 고위험군 판정 시 사용자에게 제공하는 유용한 인지 건강 정보 및 가이드

**주요 속성:**
- `id`: 솔루션 PK  
- `riskLevel`: 대상 위험도 등급  
- `title`: 안내 제목  
- `content`: 상세 솔루션 및 권고사항 내용

## 4. 도메인 관계 모델 (ERD 개념)
```
┌──────────────┐         ┌──────────────┐
│    Member    │         │    Survey    │
│──────────────│         │──────────────│
│ id (PK)      │         │ id (PK)      │
│ email        │         │ examType     │
│ password     │         │ title        │
│ gender       │         └──────┬───────┘
│ birthYear    │                │ 1
│ status       │                │
└──────┬───────┘                │ N
       │ 1               ┌──────┴───────┐
       │                 │   Question   │
       │ N               │──────────────│
┌──────┴───────┐         │ id (PK)      │
│  ExamResult  │         │ survey_id    │
│──────────────│         │ questionNum  │
│ id (PK)      │         │ content      │
│ member_id    │         └──────────────┘
│ examType     │
│ memoryScore  │
│ otherScore   │
│ adlScore     │
│ totalScore   │
│ riskLevel    │
│ createdAt    │
└──────────────┘
```
**관계 요약:**
| 관계 | 설명 |
| :--- | :--- |
| Member 1:N ExamResult | 한 회원이 여러 번 검사를 수행하고 이력 누적 |
| Survey 1:N Question | 하나의 설문지가 여러 문항을 포함 |

## 5. Enum 정의

### 5.1 ExamType (검사 유형)

| 값 | 설명 |
| :--- | :--- |
| `KDSQ_P` | 5문항 축약형 인지선별검사 (1차) |
| `KDSQ_C` | 15문항 상세형 인지선별검사 (2차) |

### 5.2 RiskLevel (위험도 및 결과 등급)

| 값 | 설명 |
| :--- | :--- |
| `NORMAL` | 정상 범위 (KDSQ-C 0~5점) |
| `HIGH_RISK` | 고위험군 (KDSQ-P 4점 이상 등) |
| `DEMENTIA_SUSPECTED` | 치매 의심 / 정밀 검진 권고 (KDSQ-C 6~30점) |

### 5.3 Gender (성별)

| 값 | 설명 |
| :--- | :--- |
| `MALE` | 남성 |
| `FEMALE` | 여성 |

### 5.4 UserStatus (회원 상태)

| 값 | 설명 |
| :--- | :--- |
| `ACTIVE` | 정상 활성 회원 |
| `WITHDRAWN` | 탈퇴 회원 |
