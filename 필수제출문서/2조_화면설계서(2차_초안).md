## 1. 문서 개요

### 1.1 화면 설계 목표

본 시스템은 사용자가 로그인 후 KDSQ 기반 인지선별검사를 단계적으로 수행하고, 검사 결과와 과거 검사 이력을 확인할 수 있도록 구성한다. 통계 기능은 개인(사용자) 대상이 아닌 관리자(병원 관계자) 대상으로 제공한다.

### 1.2 시스템 구성 전제

- **사용자(User) 프론트엔드**: React SPA
- **관리자(Admin) 페이지**: Spring MVC + Thymeleaf 서버사이드 렌더링 (React 미사용, 별도 아키텍처)
- **데이터베이스**: 병원 로컬 DB(의뢰 기관 내부망). 개발사는 데이터 접근 없이 소프트웨어 유지보수만 수행
- **권한 3그룹**
  1. 개인(회원) → User 화면
  2. 병원관계자 → Admin 화면 (Thymeleaf)
  3. 개발자(당사) → 유지보수 전용, 운영 데이터 접근 없음
- **로그인 필수**: 비회원 검사 플로우 없음 (미도입 시 예외 케이스 증가로 구현 부담 상승 판단)
- **회원정보**: 가입 후 수정 불가 (수정 폼 미제공, 안내 노티로 대체)

### 1.3 핵심 흐름

```text
회원가입
   ↓
로그인
   ↓
검사 메인
   ↓
KDSQ-P 5문항 검사
   ↓
점수 자동 산출
   ├── 4점 미만 → 정상 → 결과 화면
   │
   └── 4점 이상 → 주의 → KDSQ-C (2차) 상세검사로 전환
                                ↓
                      15문항 응답 → 영역별 점수 산출
                      memoryScore + otherScore + adlScore = totalScore
                                ↓
                         ┌──────┴──────┐
                         ↓             ↓
                     6점 미만       6점 이상
                      주의          고위험군
                         └──────┬──────┘
                                ↓
                             결과 화면
                                ↓
                    마이페이지 (검사 이력 확인)
```

# 2. 사이트맵

## 2.1 사용자(user) 

```text
/
├── /login
├── /register
├── /surveys              KDSQ-P(1차) 5문항
├── /surveys/detail       KDSQ-C(2차) 15문항
├── /results              검사 결과 (위험도 / 영역별 점수 / 솔루션 안내)
└── /mypage               회원정보(조회 전용) / 검사 이력
```

## 2.2 관리자(Admin) — Spring MVC + Thymeleaf

```text
/admin/login
/admin/dashboard              대시보드 (종합/항목별 통계, 위험도 분포)
/admin/members                회원 목록 (검색/필터)
/admin/members/{id}           회원 상세 + 검사 이력
/admin/exams                  검사 결과 목록 (정상/주의/고위험 필터)
/admin/exams/{id}             검사 상세 결과 (+ 매칭 솔루션 정보, 읽기 전용)
```

| ----- | -------------------- |

```text
│                               (각 페이지 내용)                            │
│                                                                          │
├──────────────────────────────────────────────────────────────────────────┤
│  Footer: ⓒ 2026 마음 기억                                                │

```

```text
resources/templates/
├── admin/
│   ├── layout.html        공통 레이아웃 (th:fragment)
│   ├── dashboard.html
│   ├── members/
│   │   ├── list.html
│   │   └── detail.html
│   └── exams/
│       ├── list.html
│       └── detail.html
```

## 4.3 제외된 화면 및 사유

| 화면 | 사유 |
| --- | --- |
| 통계 비교(구 SCR-07, 사용자용) | 연령 평균 비교 등 개인 통계 불필요로 확정 → 통계는 Admin 대시보드로 통합 |

| 솔루션 관리(Admin, 별도 화면) | 통계 항목에는 "솔루션"이 있으나 구현 확정 항목에서는 제외 → 검사 상세 결과 화면 내 텍스트로만 노출 |

### 5.4.4 문항 영역 및 점수 구성

KDSQ-C는 총 15문항으로 구성되며, 문항 번호에 따라 3개 영역으로 구분하여 점수를 집계한다.

| --------------------- | ----- | ------------- | -------------------- |

| **전체**                | 1~15  | `totalScore`  | 3개 영역 점수의 합계         |

**총점 계산**
```text
memoryScore = Q1 + Q2 + Q3 + Q4 + Q5

otherScore = Q6 + Q7 + Q8 + Q9 + Q10

adlScore = Q11 + Q12 + Q13 + Q14 + Q15

totalScore = memoryScore + otherScore + adlScore
```

> ⚠️ **확인 필요**: "솔루션"이 통계 항목에는 포함되어 있으나 "솔루션 안내" 자체는 Admin 구현 항목에서 제외됨. 본 문서는 별도 관리 화면 없이 검사 상세 결과 내 읽기 전용 텍스트로만 반영했습니다. 맞는 방향인지 확인 부탁드립니다.
