# KDSQ 인지선별검사 플랫폼 화면 설계서

## 1. 문서 개요

### 1.1 화면 설계 목표

본 시스템은 사용자가 로그인 후 KDSQ 기반 인지선별검사를 단계적으로 수행하고, 검사 결과와 과거 검사 이력을 확인할 수 있도록 구성한다. 통계 기능은 개인(사용자) 대상이 아닌 관리자(병원 관계자) 대상으로 제공한다.

### 1.2 시스템 구성 전제

- **사용자(User) 프론트엔드**: React SPA
- **관리자(Admin) 페이지**: Spring MVC + Thymeleaf 서버사이드 렌더링 (React 미사용, 별도 아키텍처)
- **데이터베이스**: 병원 로컬 DB(의뢰 기관 내부망). 개발사는 데이터 접근 없이 소프트웨어 유지보수만 수행
- **권한 3그룹**
  1. 개인(회원) → User 화면
  2. 병원관계자 → Admin 화면 (Thymeleaf, 확정)
  3. 개발자(당사) → 유지보수 전용, 운영 데이터 접근 없음
- **로그인 필수**: 비회원 검사 플로우 없음 (미도입 시 예외 케이스 증가로 구현 부담 상승 판단)
- **회원정보**: 가입 후 수정 불가 (수정 폼 미제공, 안내 노티로 대체)

### 1.3 핵심 흐름

```text
회원가입
   ↓
로그인
   ↓
검사 메인
   ↓
KDSQ-P 5문항 검사
   ↓
점수 자동 산출
   ├── 4점 미만 → 정상 → 결과 화면
   │
   └── 4점 이상 → KDSQ-C (2차) 상세검사로 전환
                    ↓
              15문항 응답 → 영역별 점수 산출
              memoryScore + otherScore + adlScore = totalScore
                    ↓
             ┌──────┴──────┐
             ↓             ↓
         6점 미만       6점 이상
          주의          고위험군
             └──────┬──────┘
                    ↓
                 결과 화면
                    ↓
        마이페이지 (검사 이력 확인)
```

> ⚠️ **확인 필요**: 1차 "4점 이하" 구간 내에서 정상/위험을 세부적으로 나누는 기준이 논의 내용에 명시되지 않아, 본 문서는 "4점 이하 = 정상"으로 단일 판정하여 설계했습니다. 세부 기준이 있다면 알려주세요.

> 통계(종합점수/항목별 점수)는 더 이상 사용자 화면에 존재하지 않으며, 관리자 대시보드로 이관되었습니다.

# 6. SCR-02 회원가입 화면

## 6.1 화면 목적

이름, 이메일, 비밀번호와 최소한의 인구학적 정보(성별, 출생년도)를 입력하여 회원가입한다.

## 6.2 와이어프레임

```text
┌──────────────────────────────────────────────┐
│                 회원가입                      │
│                                              │
│ 이름                                         │
│ [________________________________]           │
│                                              │
│ 이메일                                       │
│ [________________________________]           │
│                                              │
│ 비밀번호                                     │
│ [________________________________]           │
│                                              │
│ 비밀번호 확인                                │
│ [________________________________]           │
│                                              │
│ 성별                                         │
│ ○ 남성       ○ 여성                          │
│                                              │
│ 출생년도                                     │
│ [________] 년                                │
│                                              │
│                                              │
│ [             회원가입             ]          │
│                                              │
│                 로그인으로                    │
└──────────────────────────────────────────────┘
```

## 6.3 입력 항목

| 항목      | 타입       | 필수 |
| ------- | -------- | -- |
| 이름      | Text   | O  |
| 이메일     | Email    | O  |
| 비밀번호    | Password | O  |
| 비밀번호 확인 | Password | O  |
| 성별      | Radio    | O  |
| 출생년도    | Number   | O  |

회원의 핵심 속성은 이름, 이메일, 암호화된 비밀번호, 출생년도, 학력, 회원 상태로 정의되어 있다.

## 6.4 API

```text
POST /api/auth/register
```

## 6.5 유효성 검사

```text
□ 이름 입력 확인
□ 이메일 형식 확인
□ 이메일 중복 확인
□ 비밀번호 입력 확인
□ 비밀번호 확인 일치 여부
□ 성별 선택
□ 출생년도 입력
```

### 6.6 회원정보 수정 정책 (신규)

- 회원가입 이후 **회원정보 수정 기능은 제공하지 않는다.**
- 마이페이지에는 수정 폼 대신 "회원정보는 가입 후 수정할 수 없습니다." 안내 문구(Notice)만 노출한다.
- 관리자 화면에서 수정할 수 있다.

# 8. SCR-04 KDSQ-C 상세검사 화면 (2차)

## 8.1 화면 목적

KDSQ-P에서 4점 이상을 받은 사용자에게 15문항의 상세검사를 제공한다.

## 8.2 와이어프레임

```text
┌─────────────────────────────────────────────────────────┐
│ KDSQ                    상세 인지검사                   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│             KDSQ-C 상세검사                              │
│                                                         │
│              진행률 7 / 15                              │
│       ━━━━━━━━━━━━━━━━━━━░░░░░░░                        │
│                                                         │
│       Q7. 현재 상황을 이해하고                           │
│           적절하게 대처하는 데                            │
│           어려움이 있습니까?                             │
│                                                         │
│       ○ 전혀 그렇지 않다                                 │
│       ○ 가끔 그렇다                                      │
│       ○ 자주 그렇다                                      │
│                                                         │
│                 [이전] [다음]                           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 8.3 영역 구분 및 점수 필드 (신규 반영)

| 영역 | 문항 | 점수 필드 |
| --- | --- | --- |
| 기억력 (KDSQ-M) | 1~5 | `memoryScore` |
| 기타 인지기능 (KDSQ-O) | 6~10 | `otherScore` |
| 일상생활수행능력 (KDSQ-A) | 11~15 | `adlScore` |

```text
totalScore = memoryScore + otherScore + adlScore
```

> **데이터 저장 정책**: 문항별 개별 응답(answers)은 저장하지 않고, `memoryScore` / `otherScore` / `adlScore` / `totalScore` 만 `ExamResult`에 저장한다. 이 점수를 기반으로 영역별 통계(Admin 대시보드)를 제공한다.

## 8.4 API

```text
GET  /api/surveys/c
POST /api/exams/c
```

## 8.5 제출 후 처리

```text
15문항 제출
     ↓
영역별 점수 계산 (memoryScore / otherScore / adlScore)
     ↓
totalScore 계산
     ↓
위험도 판정
  ├── 6점 이하 → 주의
  └── 6점 초과 → 고위험군 / 치매등급
     ↓
결과 화면
(문항별 응답은 저장하지 않음)
```

# 9. SCR-05 검사 결과 화면

## 9.1 화면 목적

검사가 완료된 후 총점, 영역별 점수, 위험도 및 맞춤 솔루션을 제공한다.

## 9.2 정상 결과 와이어프레임

```text
┌─────────────────────────────────────────────────────────┐
│ KDSQ                    검사 결과                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    검사 결과                             │
│                                                         │
```

```text
대시보드(통계) / 회원관리 / 검사결과관리
```
