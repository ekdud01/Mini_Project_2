# KDSQ 인지선별검사 플랫폼 화면 설계서

## 1. 문서 개요

### 1.1 화면 설계 목표

본 시스템은 사용자가 로그인 후 KDSQ 기반 인지선별검사를 단계적으로 수행하고, 검사 결과와 과거 검사 추이 및 전체 사용자 통계를 확인할 수 있도록 구성한다.

핵심 흐름은 다음과 같다.

```text
회원가입
   ↓
로그인
   ↓
검사 메인
   ↓
KDSQ-P 5문항 검사
   ↓
점수 자동 산출
   ├── 0~3점 → 정상 → 결과 화면
   │
   └── 4~10점 → KDSQ-C 상세검사
                    ↓
              15문항 점수 산출
                    ↓
             ┌──────┴──────┐
             ↓             ↓
          0~5점           6~30점
          주의          고위험군
             └──────┬──────┘
                    ↓
                 결과 화면
                    ↓
        맞춤 솔루션 / 검사 이력 / 통계
```

KDSQ-P에서 4점 이상이면 KDSQ-C를 추가 진행하고, KDSQ-C는 0 ~ 5점과 6 ~ 30점 기준으로 위험도를 구분한다.

# 5. SCR-01 로그인 화면

## 5.1 화면 목적

등록된 사용자가 이메일과 비밀번호를 이용하여 로그인한다.

## 5.2 와이어프레임

```text
┌──────────────────────────────────────────────┐
│                                              │
│                    KDSQ                      │
│              인지선별검사 플랫폼               │
│                                              │
│   이메일                                      │
│   ┌──────────────────────────────────────┐   │
│   │ example@email.com                    │   │
│   └──────────────────────────────────────┘   │
│                                              │
│   비밀번호                                    │
│   ┌──────────────────────────────────────┐   │
│   │ ●●●●●●●●                             │   │
│   └──────────────────────────────────────┘   │
│                                              │
│   ┌──────────────────────────────────────┐   │
│   │                 로그인                │   │
│   └──────────────────────────────────────┘   │
│                                              │
│                회원가입하기                   │
│                                              │
└──────────────────────────────────────────────┘
```

## 5.3 구성 요소

| 컴포넌트      | 역할          |
| --------- | ----------- |
| LoginPage | 로그인 전체 화면   |
| LoginForm | 이메일/비밀번호 입력 |
| Input     | 이메일 및 비밀번호  |
| Button    | 로그인         |
| Link      | 회원가입 이동     |

## 5.4 상태

```text
email
password
loading

```

## 5.5 API

```text
POST /api/auth/login
```

로그인 성공 시 JWT 액세스 토큰 및 리프레시 토큰을 발급하는 구조를 따른다.

## 5.6 예외 상태

```text
[빈 값]
→ "이메일과 비밀번호를 입력해주세요."

[잘못된 계정]
→ "이메일 또는 비밀번호를 확인해주세요."

[로그인 요청 중]
→ 버튼 비활성화 + 로딩 표시
```

# 6. SCR-02 회원가입 화면

## 6.1 화면 목적

이메일, 비밀번호와 인구학적 정보를 입력하여 회원가입한다.

## 6.2 와이어프레임

```text
┌──────────────────────────────────────────────┐
│                 회원가입                      │
│                                              │
│ 이름                                         │
│ [________________________________]           │
│                                              │
│ 이메일                                       │
│ [________________________________]           │
│                                              │
│ 비밀번호                                     │
│ [________________________________]           │
│                                              │
│ 비밀번호 확인                                │
│ [________________________________]           │
│                                              │
│ 성별                                         │
│ ○ 남성       ○ 여성                          │
│                                              │
│ 출생년도                                     │
│ [________] 년                                │
│                                              │
│                                              │
│ [             회원가입             ]          │
│                                              │
│                 로그인으로                    │
└──────────────────────────────────────────────┘
```

## 6.3 입력 항목

| 항목      | 타입       | 필수 |
| ------- | -------- | -- |
| 이름      | Text   | O  |
| 이메일     | Email    | O  |
| 비밀번호    | Password | O  |
| 비밀번호 확인 | Password | O  |
| 성별      | Radio    | O  |
| 출생년도    | Number   | O  |

회원의 핵심 속성은 이름, 이메일, 암호화된 비밀번호, 출생년도, 학력, 회원 상태로 정의되어 있다.

## 6.4 API

```text
POST /api/auth/register
```

## 6.5 유효성 검사

```text
□ 이름 형식 확인
□ 이메일 형식 확인
□ 이메일 중복 확인
□ 비밀번호 입력 확인
□ 비밀번호 확인 일치 여부
□ 성별 선택
□ 출생년도 입력
```

# 8. SCR-04 KDSQ-C 상세검사 화면

## 8.1 화면 목적

KDSQ-P에서 4점 이상을 받은 사용자에게 15문항의 상세검사를 제공한다.

## 8.2 와이어프레임

```text
┌─────────────────────────────────────────────────────────┐
│ KDSQ                    상세 인지검사                   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│             KDSQ-C 상세검사                              │
│                                                         │
│              진행률 7 / 15                              │
│       ━━━━━━━━━━━━━━━━━━━░░░░░░░                        │
│                                                         │
│       Q7. 현재 상황을 이해하고                           │
│           적절하게 대처하는 데                            │
│           어려움이 있습니까?                             │
│                                                         │
│       ○ 전혀 그렇지 않다                                 │
│       ○ 가끔 그렇다                                      │
│       ○ 자주 그렇다                                      │
│                                                         │
│                 [이전] [다음]                           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 8.3 영역 구분

도메인 설계서에서는 KDSQ-C의 15문항을 다음 영역으로 관리한다.

| 영역            | 문항    |
| ------------- | ----- |
| 기억력 Memory    | 1~5   |
| 기타 인지기능 Other | 6~10  |
| 일상생활수행능력 ADL  | 11~15 |

각 영역의 점수를 합산하여 총점을 산출한다.

## 8.4 API

```text
GET  /api/surveys/c
POST /api/exams/c
```

## 8.5 제출 후 처리

```text
15문항 제출
     ↓
영역별 점수 계산
     ↓
총점 계산
     ↓
위험도 판정
     ↓
결과 화면
```

# 9. SCR-05 검사 결과 화면

## 9.1 화면 목적

검사가 완료된 후 총점, 영역별 점수, 위험도 및 맞춤 솔루션을 제공한다.

## 9.2 정상 결과 와이어프레임

```text
┌─────────────────────────────────────────────────────────┐
│ KDSQ                    검사 결과                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    검사 결과                             │
│                                                         │
│                 정상 범위입니다                          │
│                                                         │
│                  총점  3점 / 10점                        │
│                                                         │
│                                                         │
│       검사일시 : 2026-09-22                              │
│                                                         │
│       [검사 이력 보기]       [통계 비교]                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 9.3 고위험군 결과 와이어프레임

```text
┌─────────────────────────────────────────────────────────┐
│                    검사 결과                            │
│                                                         │
│              인지기능 저하 의심                          │
│                                                         │
│                  총점  12점                             │
│                                                         │
│       ┌────────────────────────────────┐                │
│       │ 기억력              4점         │                │
│       │ 기타 인지기능        4점         │                │
│       │ 일상생활수행능력     4점         │                │
│       └────────────────────────────────┘                │
│                                                         │
│       ───── 권장 안내 ─────                              │
│                                                         │
│       인지 건강을 위한 관리 정보                         │
│       및 추가적인 검진 관련 안내를 확인하세요.            │
│                                                         │
│       [맞춤 솔루션 확인]                                 │
│                                                         │
│       [검사 이력 보기]       [통계 비교]                │
└─────────────────────────────────────────────────────────┘
```

## 9.4 위험도 기준

| 검사     |   점수 | 결과                |
| ------ | ---: | -------------------- |
| KDSQ-P |  0~3 | 정상                |
| KDSQ-P | 4~10 | KDSQ-C 추가 검사      |
| KDSQ-C |  0~5 | 주의           |
| KDSQ-C | 6~30 | 인지기능 저하 의심(주의) / 고위험군 |

> 화면의 결과 문구는 검사 결과를 의료적 확진으로 표현하지 않고, 도메인에서 정의한 "정상", "주의", "고위험군" 표현을 기준으로 한다.

## 9.5 API

```text
GET /api/exams/{id}/result
```

    ↓

    ↓

# 23. 핵심 설계 요약

본 화면 설계서는 다음 구조를 기준으로 구현한다.

```text
회원
 ↓
로그인
 ↓
KDSQ-P
 ↓
점수 판정
 ├── 정상 → 결과
 └── 4점 이상
       ↓
     KDSQ-C
       ↓
     결과 판정
       ├── 정상
       └── 고위험군 → 솔루션
                    ↓
              결과 저장
                    ↓
              마이페이지
                    ↓
              통계 비교
```

**핵심 컴포넌트**

```text
Header
LoginForm
RegisterForm
QuestionCard
ProgressBar
AnswerOptions
ScoreCard
RiskBadge
SolutionCard
ExamHistoryTable
ExamTrendChart
StatisticsChart
ProtectedRoute
```

**핵심 데이터**

```text
Member
Survey
Question
ExamResult
Solution
```

**핵심 비즈니스 규칙**

```text
KDSQ-P 0~3점
→ 정상

KDSQ-P 4~10점
→ KDSQ-C 추가 검사

KDSQ-C 0~5점
→ 정상

KDSQ-C 6~30점
→ 인지기능 저하 의심 / 고위험군

검사 결과
→ 날짜별 누적 저장
→ 마이페이지 시계열 추이
→ 전체 사용자 통계 비교
→ 고위험군 맞춤 솔루션
```

이 구조를 기준으로 구현하면 **화면 설계 → React 컴포넌트 → 상태 관리 → API 연동**까지 일관된 형태로 연결할 수 있다.
