## 1. Entity 설계 개요

### 1.1 설계 목적
> JPA Entity 클래스 설계를 통해 객체-관계 매핑(ORM)을 정의하고,
> KDSQ 인지선별검사 비즈니스 도메인을 코드로 표현하여 데이터 무결성과 유지보수성이 용이한 시스템을 구축

### 1.2 설계 원칙
- **단일 책임 원칙**: 하나의 Entity는 하나의 비즈니스 개념만 표현
- **소프트 삭제(Soft Delete) 적용**: 회원 탈퇴 시 UserStatus를 WITHDRAWN으로 변경하여 검사 통계 및 이력 데이터의 정합성 유지
- **캡슐화 및 불변성**: 비즈니스 로직을 Entity 내부에 구현하고 무분별한 Setter 지양
- **연관관계 최소화**: 필요한 관계만 매핑하여 복잡도 감소

### 1.3 기술 스택
- **ORM 프레임워크**: Spring Data JPA [Version]
- **데이터베이스**: MariaDB [Version]
- **검증 프레임워크**: Bean Validation [Version]
- **감사 기능**: Spring Data JPA Auditing

### 4.3 ExamResult Entity

#### 4.3.1 필드 상세 명세
| 필드명 | 데이터 타입 | 컬럼명 | 제약조건 | 설명 | 비즈니스 규칙 |
|--------|-------------|--------|----------|------|---------------|
| **id** | `Long` | `result_id` | PK, NOT NULL, AUTO_INCREMENT | 검사결과 고유 식별자 | 시스템 자동 생성 |
| **examType** | `ExamType` | `exam_type` | NOT NULL, ENUM | 검사 유형 | KDSQ_P, KDSQ_C |
| **pScore** | `Integer` | `p_Score` | NOT NULL, DEFAULT(0) | 1차 검사 점수 | KDSQ-P 단독 검사 시 해당 점수 저장 / KDSQ-C 진입 시 선행 1차 점수 백업 |
| **memoryScore** | `Integer` | `memory_score` | NOT NULL, DEFAULT(0) | 기억력 영역 점수 | KDSQ-C (1~5번 합산) |
| **otherScore** | `Integer` | `other_score` | NOT NULL, DEFAULT(0) | 기타 인지기능 영역 점수 | KDSQ-C (6~10번 합산) |
| **adlScore** | `Integer` | `adl_score` | NOT NULL, DEFAULT(0) | 일상생활 수행능력 점수 | KDSQ-C (11~15번 합산) |
| **riskLevel** | `RiskLevel` | `risk_level` | NOT NULL, ENUM | 판정 등급 | Normal, Borderline, HighRisk |

#### 4.3.2 구현 코드 예시
```java
/**
 * 검사결과 Entity
 */
@Entity
@Table(name = "exam_results")
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@Getter
public class ExamResult extends BaseEntity {

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "member_id", nullable = false)
    private Member member;

    @Enumerated(EnumType.STRING)
    @Column(name = "exam_type", nullable = false)
    private ExamType examType;

    @Column(name = "p_Score")
    private Integer pScore; // KDSQ-P 단독 검사 점수 또는 KDSQ-C 진입 시 1차 선행 점수 보관

    @Column(name = "memory_score", nullable = false)
    private Integer memoryScore = 0;

    @Column(name = "other_score", nullable = false)
    private Integer otherScore = 0;

    @Column(name = "adl_score", nullable = false)
    private Integer adlScore = 0;

    @Enumerated(EnumType.STRING)
    @Column(name = "risk_level", nullable = false)
    private RiskLevel riskLevel;

    // 비즈니스 메서드
    public int getTotalScore() {
        if (this.examType == ExamType.KDSQ_P) {
            return this.pScore != null ? this.pScore : 0;
        }
        return this.memoryScore + this.otherScore + this.adlScore;
    }

    public static ExamResult createResult(Member member, ExamType examType, Integer pScore,
                                          int memoryScore, int otherScore, int adlScore) {
        ExamResult result = new ExamResult();
        result.member = member;
        result.examType = examType;
        result.pScore = pScore;
        result.memoryScore = memoryScore;
        result.otherScore = otherScore;
        result.adlScore = adlScore;
        result.riskLevel = result.evaluateRisk();
        return result;
    }

    private RiskLevel evaluateRisk() {
        if (this.examType == ExamType.KDSQ_P) {
            int score = this.pScore != null ? this.pScore : 0;
            return (score <= 3) ? RiskLevel.Normal : RiskLevel.Borderline;
        } else {
            int total = getTotalScore();
            return (total <= 5) ? RiskLevel.Borderline : RiskLevel.HighRisk;
        }
    }
}
```

## 6. 연관관계 매핑 전략

### 6.1 연관관계 매핑 규칙
| 관계 유형 | 기본 전략 | 이유 | 예외 상황 |
|----------|-----------|------|-----------|
| **@ManyToOne** | LAZY | 성능 최적화 | 필수 조회 데이터는 EAGER |
| **@OneToMany** | LAZY | N+1 문제 방지 | 소량 데이터는 EAGER |
| **@OneToOne** | LAZY | 일관성 유지 | 항상 함께 조회하는 경우 EAGER |
| **@ManyToMany** | 사용 금지 | 복잡성 증가 | 중간 테이블로 대체 |

### 6.2 Cascade 옵션 가이드

## 7. 감사(Auditing) 설정

### 7.1 BaseEntity 구현
```java
@MappedSuperclass
@EntityListeners(AuditingEntityListener.class)
@Getter
public abstract class BaseEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "id")
    private Long id;

    @CreatedDate
    @Column(name = "created_at", nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @LastModifiedDate
    @Column(name = "updated_at")
    private LocalDateTime updatedAt;

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        BaseEntity that = (BaseEntity) o;
        return Objects.equals(id, that.id);
    }

    @Override
    public int hashCode() {
        return Objects.hash(id);
    }
}
```

### 7.2 Auditing 설정
```java
@Configuration
@EnableJpaAuditing
public class JpaAuditingConfig {

    @Bean
    public AuditorAware<String> auditorProvider() {
        return () -> {
            Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
            if (authentication == null || !authentication.isAuthenticated()) {
                return Optional.of("SYSTEM");
            }
            return Optional.of(authentication.getName());
        };
    }
}
```
