# 3. STEP 1 — 페이지 목록 만들기

## 3.1 "어떤 화면이 필요한가?" 질문하기

사용자가 무엇을 할 수 있어야 하는가?
* [x] 회원가입을 한다 (이메일, 비밀번호 및 인구학적 정보 입력)
* [x] 로그인한다
* [x] 1차 KDSQ-P(5문항) 검사를 진행한다
* [x] 1차 검사 결과에 따라 2차 KDSQ-C(15문항) 상세 검사를 진행한다

* [x] 고위험군 판정 시 맞춤 솔루션 및 유용한 정보를 확인한다

## 3.2 URL 구조 (사이트맵) 작성

할 수 있는 것들을 URL로 연결합니다:
```
React 화면 (사용자 영역):
├── /login                 → 로그인 페이지
├── /register              → 회원가입 페이지
├── /surveys               → 검사 메인 (KDSQ-P 시작)
├── /surveys/detail        → KDSQ-C 상세 검사 페이지 (4점 이상 시)
├── /results               → 검사 결과 및 솔루션 안내 페이지
├── /mypage                → 내 검사 이력 및 시계열 그래프 추이
└── /statistics            → 전체 사용자 통계 비교 페이지
```
---

## 3.3 페이지 설계서 표 작성

| 페이지명 | URL | 주요 기능 | 필요한 API |
| :--- | :--- | :--- | :--- |
| **로그인** | `/login` | 이메일/비밀번호 입력, 로그인 | `POST /api/auth/login` |
| **회원가입** | `/register` | 이메일/비밀번호, 성별, 출생년도, 학력 입력 | `POST /api/auth/register` |
| **검사 메인** | `/surveys` | KDSQ-P (5문항) 자가검진 응시 | `GET /api/surveys/p`, `POST /api/exams/p` |
| **상세 검사** | `/surveys/detail` | KDSQ-C (15문항) 추가 검사 응시 (4점 이상) | `GET /api/surveys/c`, `POST /api/exams/c` |
| **검사 결과** | `/results` | 점수 확인, 위험도 판정(정상/고위험군), 맞춤 솔루션 제공 | `GET /api/exams/{id}/result` |
| **마이페이지** | `/mypage` | 회원 정보 수정, 과거 검사 이력, 시계열 그래프 추이 조회 | `GET /api/members/me`, `GET /api/exams/history` |
| **통계 비교** | `/statistics` | 전체 사용자 평균치 및 본인 위치(이상치/평균치) 비교 | `GET /api/statistics/comparison` |
