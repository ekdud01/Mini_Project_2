## 1. 컴포넌트 개요

### 1.1 컴포넌트 목록

| 화면 ID | 화면명 | 페이지 컴포넌트 | URL | 권한 |
|---|---|---|---|---|
| SCR-01 | 로그인 | `LoginPage` | `/login` | 공개 |
| SCR-02 | 회원가입 | `RegisterPage` | `/register` | 공개 |
| SCR-03 | KDSQ-P 1차 검사 | `SurveyPage` (`type="P"`) | `/surveys` | 로그인 필요 |
| SCR-04 | KDSQ-C 2차 검사 | `SurveyPage` (`type="C"`) | `/surveys/c` | 로그인 필요 |
| SCR-05 | 검사 결과 | `ResultPage` | `/results/:examId` | 로그인 필요 |
| SCR-06 | 마이페이지 | `MyPage` | `/mypage` | 로그인 필요 |

> SCR-03과 SCR-04는 화면 구성이 동일하여 `SurveyPage` 하나로 만들고 `type`으로 구분합.

### 1.2 목적 및 역할

- **주요 목적**: 회원가입·로그인 후 KDSQ-P(1차) → KDSQ-C(2차) 인지선별검사를 진행하고, 결과와 검사 이력을 조회하는 사용자 화면 구현
- **위치**: `src/pages/`(페이지), `src/components/`(레이아웃·공통)
- **컴포넌트 유형**: 페이지 / 레이아웃 / 기능 / 공통 컴포넌트

### 1.3 기능 요구사항

- [ ] 로그인·회원가입 (입력 검증, 401 실패 문구, 409 이메일 중복 안내)
- [ ] KDSQ-P 5문항 검사 → 0–3점 결과 화면 / 4–10점 KDSQ-C 안내 후 `/surveys/c`
- [ ] KDSQ-C 15문항 검사 → 영역별 점수 산출·저장 → 결과 화면
- [ ] 검사 결과 표시 (총점·판정, KDSQ-C는 영역별 점수 + 관리 안내)
- [ ] 마이페이지 (회원정보 조회 전용, 검사 이력, 점수 추이, 이력 없음 안내)
- [ ] 로딩 / 오류 / 빈 데이터 상태 처리, 비로그인 접근 시 `/login` 이동

## 2. 컴포넌트 구조 설계

### 2.1 컴포넌트 트리

```
UserLayout                              ← 공통 레이아웃 (Header + Outlet + Footer)
  ├── LoginPage                         ← 상태 소유, 로그인 API 호출
  │     └── LoginForm                   ← (Props: onSubmit, isLoading, errorMessage) 입력·검증
  ├── RegisterPage                      ← 상태 소유, 회원가입 API 호출, 입력 폼
  └── ProtectedRoute                    ← 비로그인 시 /login 이동
        ├── SurveyPage                  ← 상태 소유, 문항 조회·결과 제출 (P/C 공용)
        │     ├── SurveyHeader          ← (Props: type) 검사명·안내 문구
        │     ├── ProgressBar           ← (Props: current, total) 진행률
        │     ├── QuestionCard          ← (Props: question) 문항 표시
        │     │     └── AnswerOptions   ← (Props: value, onChange) 답변 선택
        │     ├── PreviousButton        ← (Props: isDisabled, onClick) 이전 문항
        │     ├── NextButton            ← (Props: onClick) 다음 문항
        │     └── SubmitButton          ← (Props: isSubmitting, onClick) 마지막 문항 제출
        ├── ResultPage                  ← 상태 소유, 결과 조회 API 호출
        │     ├── ResultHeader          ← 결과 제목
        │     ├── ResultStatus          ← (Props: exam) 정상/주의/위험 표시
        │     ├── TotalScore            ← (Props: score, maxScore) 총점
        │     ├── ScoreSummary          ← (Props: memoryScore, otherScore, adlScore) 영역별 점수 (KDSQ-C)
        │     ├── ExamDate              ← (Props: date) 검사일시
        │     ├── Recommendation        ← (Props: riskLevel) 관리·추가 검진 안내 (KDSQ-C)
        │     └── HistoryButton         ← (Props: onClick) /mypage 이동
        └── MyPage                      ← 상태 소유, 회원정보·이력 조회 API 호출
              ├── ProfileCard           ← (Props: member) 회원정보 조회
              │     └── ReadOnlyNotice  ← 수정 불가 안내
              ├── ExamHistoryTable      ← (Props: exams, onDetail) 검사 이력 목록
              │     └── RiskBadge       ← (Props: riskLevel) 판정 배지
              ├── ExamTrendChart        ← (Props: exams) 점수 추이
              └── EmptyHistory          ← (Props: onStart) 이력 없음 안내
```

> 로딩·오류 표시는 공통 `LoadingSpinner` / `Alert`를 사용합니다.

### 2.2 컴포넌트 분류 및 책임

| 컴포넌트 | 타입 | 파일 위치 | 주요 책임 | 상태 관리 | 재사용성 |
|---|---|---|---|---|---|

| `ResultPage` | 페이지 | `pages/Result/index.jsx` | 결과 조회·표시 | Zustand | 낮음 |
| `MyPage` | 페이지 | `pages/MyPage/index.jsx` | 회원정보·이력 조회 | Zustand | 낮음 |
| `LoginForm` | 기능 | `pages/Login/components/` | 로그인 입력·검증 | 로컬 | 보통 |
| `SurveyHeader` 외 7종 | 기능 | `pages/Survey/components/` | 검사 화면 표시 | 없음 | 보통 |

| `ProtectedRoute`, `LoadingSpinner`, `Alert` | 공통 | `components/common/` | 접근 제어, 로딩·오류/안내 표시 | `ProtectedRoute`만 Zustand | 높음 |

### 2.3 파일 구조

```
src/
├── pages/
│   └── [Login | Register | Survey | Result | MyPage]/
│       ├── index.jsx          # 페이지 컴포넌트 (상태 소유)
│       └── components/        # 이 페이지에서만 쓰는 컴포넌트
├── components/
│   ├── layout/                # UserLayout, Header, Footer

```

> type Member = {
>   name: string;                    // 이름
>   email: string;                   // 이메일
>   gender: 'MALE' | 'FEMALE';       // 성별 (남성/여성)

>

>   id: number;                      // 문항 ID

> }
>
> type Exam = {
>   examId: number;                  // 검사 결과 ID
>   examType: 'KDSQ_P' | 'KDSQ_C';   // 검사 종류

>   memoryScore: number | null;      // KDSQ-C 기억력 (10점 만점)
>   otherScore: number | null;       // KDSQ-C 기타 인지기능 (10점 만점)
>   adlScore: number | null;         // KDSQ-C 일상생활수행능력 (10점 만점)
>   riskLevel: 'Normal' | 'Borderline' | 'HighRisk';  // 정상/주의/위험
>   createdAt: string;               // 검사일시
> }
> // totalScore는 저장하지 않고 프론트에서 계산 (memory + other + adl)
> ```

## 4. 상태 관리 설계

### 4.1 상태 위치 결정 근거

| 상태명 | 위치 선택 | 결정 근거 |
|---|---|---|
| `currentIndex`, `answers` | 로컬 `useState` (`SurveyPage`) | 검사 화면 안에서만 사용, 문항별 응답은 저장하지 않음 |
| 폼 입력값, `isLoading`, `errorMessage` | 로컬 `useState` (`LoginPage`, `RegisterPage`) | 해당 화면의 입력·제출 상태 |
| `questions` | `surveyStore` | 서버 데이터 (문항 조회) |
| `currentExam`, `history` | `examStore` | 서버 데이터, 검사·결과·마이페이지에서 사용 |
| `me` | `memberStore` | 서버 데이터 (회원정보 조회) |
| `token`, `email` | `authStore` (localStorage) | 앱 전체 인증 상태, 새로고침 후 유지 |

> `totalScore`처럼 계산 가능한 값은 상태에 저장하지 않습니다.

### 4.2 Zustand 스토어

| 스토어 | 상태 | 액션 |
|---|---|---|
| `authStore` | `token`, `email` | `login()`, `logout()` |
| `surveyStore` | `questions`, `loading`, `error` | `fetchQuestions(type)` |
| `examStore` | `currentExam`, `history`, `loading`, `error` | `submitP()`, `submitC()`, `fetchExam(examId)`, `fetchHistory()` |
| `memberStore` | `me`, `loading`, `error` | `fetchMe()` |

### 4.3 점수·판정 규칙 (`utils/kdsq.js`)

```
firstScore  = Q1-Q5 합계 (10점 만점)     → 0-3 정상 / 4-10 2차 대상
memoryScore = Q1-Q5,  otherScore = Q6-Q10,  adlScore = Q11-Q15 (각 10점 만점)
totalScore  = memory + other + adl       → 0-5 주의 / 6-30 위험
```

## 5. API 연동 설계

### 5.1 API 목록

| API | 메서드 | 용도 | 호출 시점 | 인증 |
|---|---|---|---|---|
| `/api/auth/login` | POST | 로그인 | 로그인 버튼 | 불필요 |
| `/api/auth/register` | POST | 회원가입 | 회원가입 버튼 | 불필요 |
| `/api/auth/logout` | POST | 로그아웃 | Header 로그아웃 | 필요 |
| `/api/surveys/p`, `/api/surveys/c` | GET | 문항 조회 | 검사 화면 진입 | 필요 |
| `/api/exams/p`, `/api/exams/c` | POST | 검사 결과 저장 | 마지막 문항 제출 | 필요 |
| `/api/exams/:examId` | GET | 결과 조회 | 결과 화면 진입 | 필요 |
| `/api/members/me` | GET | 회원정보 조회 | 마이페이지 진입 | 필요 |
| `/api/exams/history` | GET | 검사 이력 조회 | 마이페이지 진입 | 필요 |

### 5.2 에러 처리

| 상태 | 처리 |
|---|---|
| 400 | 필드 오류 메시지 표시 |
| 401 | 로그인: "이메일 또는 비밀번호를 확인해주세요." / 그 외: 로그아웃 후 `/login` |
| 409 | "이미 가입된 이메일입니다." |
| 그 외 (404, 500, 네트워크) | 오류 메시지 + 재시도 |
