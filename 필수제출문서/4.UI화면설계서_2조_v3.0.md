## 1. 화면 목록 개요

### 1.1 사용자(User) 화면 목록

| 화면 ID | 화면명 | URL | 권한 | 화면 타입 | 주요 기능 |
|---|---|---|---|---|---|
| SCR-01 | 로그인 | `/login` | 공개 | 입력 | 이메일/비밀번호 로그인, 회원가입 이동 |
| SCR-02 | 회원가입 | `/register` | 공개 | 입력 | 이름/이메일/비밀번호/성별/출생년도 입력 및 등록 |
| SCR-03 | KDSQ-P 1차 검사 | `/surveys` | 로그인 필요 | 입력 | 5문항 검사, 점수 산출, 다음 단계 결정 |
| SCR-04 | KDSQ-C 2차 검사 | `/surveys/c` | 로그인 필요 | 입력 | 15문항 검사, 영역별 점수 산출 |
| SCR-05 | 검사 결과 | `/results/:examId` | 로그인 필요 | 상세 | 총점/영역별 점수/판정/관리 안내 표시 |
| SCR-06 | 마이페이지 | `/mypage` | 로그인 필요 | 목록/상세 | 회원정보 조회, 검사 이력, 검사 추이 |

### 1.2 관리자(Admin) 화면 목록

| 화면 ID | 화면명 | URL | 권한 | 화면 타입 | 주요 기능 |
|---|---|---|---|---|---|
| ADM-01 | 관리자 로그인 | `/admin/login` | 공개 | 입력 | 관리자 로그인, 계정 발급 안내 |
| ADM-02 | 대시보드 | `/admin/dashboard` | 관리자 | 대시보드 | 회원/검사 현황, 위험도 분포, 점수 통계 및 추이 |
| ADM-03 | 회원 목록 | `/admin/members` | 관리자 | 목록 | 이름/이메일 검색, 회원 상세 이동 |
| ADM-04 | 회원 상세 | `/admin/members/{id}` | 관리자 | 상세 | 회원정보, 검사 이력, 계정 비활성화, 수정 화면 이동 |
| ADM-04-1 | 회원 정보 수정 | `/admin/members/{id}/edit` | 관리자 | 입력 | 이름/이메일/성별/출생년도 수정 |
| ADM-05 | 검사 결과 목록 | `/admin/exams` | 관리자 | 목록 | 검사종류/위험도/이름/기간 필터, 결과 상세, 비활성화 |
| ADM-06 | 검사 상세 결과 | `/admin/exams/{id}` | 관리자 | 상세 | 점수/판정/관리 안내 조회, 회원 상세 연결, 비활성화 |

### 1.3 권한별 접근 정책

| 권한 | 접근 범위 | 비고 |
|---|---|---|
| 공개 | 로그인, 회원가입, 관리자 로그인 | 검사 및 마이페이지 접근 불가 |
| 사용자 | 공개 화면 + 검사 + 결과 + 마이페이지 | 회원정보는 조회 전용 |
| 관리자 | 관리자 로그인 후 관리자 전체 화면 | 회원정보·검사결과 관리 가능 |
| 개발자(유지보수) | 화면 설계 범위 외 | 운영 데이터 조회 권한 없음 |

### 1.4 핵심 검사 흐름

```text
회원가입
   ↓
로그인
   ↓
KDSQ-P (1차) 5문항
   ↓
firstScore 산출 (10점 만점)
   ├── 0~3점 → 정상 → 결과 화면 → 종료
   │
   └── 4~10점 → KDSQ-C (2차) 진행
                    ↓
             15문항 응답
                    ↓
      memoryScore + otherScore + adlScore 산출
             (각 10점 만점, 저장)
                    ↓
      totalScore = memory + other + adl
             (30점 만점, 프론트에서 계산)
                    ↓
             ┌──────┴──────┐
             ↓             ↓
           0~5점          6~30점
            주의           고위험군
             └──────┬──────┘
                    ↓
             결과 화면
        (관리·추가 검진 안내 포함)
                    ↓
                 마이페이지
```

> 판정 기준은 문서 전체에서 **KDSQ-P 0~3 정상 / 4~10 2차 대상**, **KDSQ-C 0~5 주의 / 6~30 고위험군**으로 통일한다.

# 3. 사용자 화면별 상세 설계

## 3.1 SCR-01 — 로그인 화면

### 3.1.1 화면 개요

| 항목 | 내용 |
|---|---|
| **화면명** | 로그인 |
| **URL** | `/login` |
| **화면 타입** | 입력 |
| **권한 레벨** | 공개 |
| **주요 기능** | 등록된 이메일과 비밀번호로 로그인 |
| **연결 API** | `POST /api/auth/login` |

### 3.1.2 와이어프레임

```text
┌──────────────────────────────────────────────┐
│ Header                                       │
├──────────────────────────────────────────────┤
│                    KDSQ                      │
│              인지선별검사 플랫폼               │
│                                              │
│   이메일                                      │
│   ┌──────────────────────────────────────┐   │
│   │ example@email.com                    │   │
│   └──────────────────────────────────────┘   │
│                                              │
│   비밀번호                                    │
│   ┌──────────────────────────────────────┐   │
│   │ ●●●●●●●●                             │   │
│   └──────────────────────────────────────┘   │
│   ※ 로그인 실패 시 오류 메시지 표시             │
│                                              │
│   ┌──────────────────────────────────────┐   │
│   │                 로그인                │   │
│   └──────────────────────────────────────┘   │
│                                              │
│               [ 회원가입하기 ]                │
└──────────────────────────────────────────────┘
```

### 3.1.3 UI 컴포넌트 매핑

| 화면 요소 | 컴포넌트 | 라이브러리 | 역할 |
|---|---|---|---|
| 로그인 컨테이너 | `LoginPage` | — | 화면 구성 및 로그인 성공 후 `/surveys` 이동 |
| 로그인 폼 | `LoginForm` | — | 입력 및 제출 처리 |
| 이메일 입력 | `Input` | shadcn/ui | 이메일 입력 |
| 비밀번호 입력 | `Input` | shadcn/ui | 비밀번호 입력 |
| 로그인 버튼 | `Button` | shadcn/ui | 로그인 제출 |
| 오류 메시지 | `Alert` | shadcn/ui | 인증/네트워크 오류 표시 |
| 회원가입 링크 | `Link` | React Router | `/register` 이동 |

### 3.1.4 화면 상태

| 상태 | 표시 내용 | 트리거 |
|---|---|---|
| 초기 | 이메일/비밀번호 입력 폼 | 화면 진입 |
| 입력 오류 | 필수값 누락 또는 이메일 형식 오류 | 제출 전 검증 |
| 로그인 진행 중 | 버튼 비활성화 + 로딩 | 로그인 버튼 클릭 |
| 로그인 실패 | "이메일 또는 비밀번호를 확인해주세요." | 401 |
| 일시적 오류 | 오류 안내 | 서버/네트워크 오류 |
| 로그인 성공 | `/surveys` 이동 | 로그인 성공 |

> 보안상 존재하지 않는 이메일과 비밀번호 불일치를 구분해 노출하지 않는다.

### 3.1.5 사용자 인터랙션 흐름

```text
[/login]
   → 이메일/비밀번호 입력
   → 로그인 클릭
   → POST /api/auth/login
      ├─ 실패 → 오류 메시지
      └─ 성공 → 토큰 저장 → /surveys 이동

[회원가입하기 클릭]
   → /register 이동
```

### 3.2.5 사용자 인터랙션 및 유효성

```text
[/login] → [회원가입하기] → [/register]
                              ↓
                        회원정보 입력
                              ↓
                       클라이언트 검증
                    ┌─────────┴─────────┐
                    ↓                   ↓
                  실패                 성공
                    ↓                   ↓
                필드 오류       POST /api/auth/register
                                      ↓
                             ┌────────┴────────┐
                             ↓                 ↓
                           200               409/400
                             ↓                 ↓
                        /login 이동      오류 표시
```

```text
이름          — 공백 아님, 1~50자
이메일        — 형식 일치, 최대 100자
비밀번호      — 공백 아님
비밀번호 확인 — password와 일치
성별          — 선택됨
출생년도      — 4자리 숫자, 1900 ~ 현재연도
```

> 회원가입 이후 사용자는 회원정보를 수정할 수 없으며, 마이페이지에서 조회 전용으로 표시한다. 관리자만 회원정보를 수정할 수 있다.

## 3.3 SCR-03 — KDSQ-P 1차 검사

### 3.3.1 화면 개요

| 항목 | 내용 |
|---|---|
| **화면명** | KDSQ-P 1차 검사 |
| **URL** | `/surveys` |
| **화면 타입** | 입력 |
| **권한 레벨** | 로그인 필요 |
| **주요 기능** | 5문항 인지선별검사 및 점수에 따른 2차 검사 여부 결정 |
| **연결 API** | `GET /api/surveys/p`, `POST /api/exams/p` |

### 3.3.2 와이어프레임

```text
┌─────────────────────────────────────────────────────────┐
│ Header                                                  │
├─────────────────────────────────────────────────────────┤
│             KDSQ-P 인지선별검사 (1차)                    │
│       간단한 인지기능 자가검사를 시작합니다.             │
│                                                         │
│                  진행률 1 / 5                            │
│       ━━━━━━━━━━━━━━━━━━━━━━━━━━━                       │
│       Q1. 최근 일어난 일을 기억하는 데                  │
│           어려움이 있습니까?                             │
│                                                         │
│       ○ 전혀 그렇지 않다                                 │
│       ○ 가끔 그렇다                                      │
│       ○ 자주 그렇다                                      │
│                                                         │
│                   [이전] [다음]                          │
└─────────────────────────────────────────────────────────┘
```

### 3.3.3 UI 컴포넌트 매핑

| 화면 요소 | 컴포넌트 | 라이브러리 | 역할 |
|---|---|---|---|
| 검사 제목 | `SurveyHeader` | Card/Typography | 검사명 및 안내 문구 |
| 진행률 | `ProgressBar` | Progress | 현재/전체 문항 표시 |
| 문항 영역 | `QuestionCard` | Card | 현재 문항 표시 |
| 답변 선택 | `AnswerOptions` | RadioGroup | 답변 선택 |
| 이전/다음 | `PreviousButton` / `NextButton` | Button | 문항 이동 |
| 제출 | `SubmitButton` | Button | 마지막 문항 제출 |
| 로딩/오류 | `LoadingSpinner` / `Alert` | 공통 | 상태 표시 |

### 3.3.4 화면 상태

| 상태 | 표시 내용 | 트리거 |
|---|---|---|
| 초기 | 1번 문항과 안내 표시 | 화면 진입 |
| 문항 로딩 중 | 로딩 표시 | `GET /api/surveys/p` |
| 검사 진행 중 | 문항/진행률/선택지 | 데이터 로딩 완료 |
| 답변 미선택 | "답변을 선택해주세요." | 다음/제출 클릭 |
| 제출 진행 중 | 제출 버튼 비활성화 + 로딩 | 마지막 문항 제출 |
| 정상 | 정상 판정 및 결과 화면 | `firstScore` 0~3 |
| 2차 대상 | KDSQ-C 안내 후 `/surveys/c` 이동 | `firstScore` 4~10 |
| 제출 실패 | 오류 메시지 | POST 실패 |

### 3.3.5 사용자 인터랙션 흐름

