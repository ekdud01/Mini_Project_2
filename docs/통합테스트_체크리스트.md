# 통합 테스트 체크리스트

| 항목 | 내용 |
|------|------|
| 프로젝트 | MEMORY ATTACK — KDSQ 인지선별검사 플랫폼 |
| 팀 | REMEMNE (리멤느) |
| 작성일 | 2026-09-30 |
| 작성자 | 윤수연 |
| 대상 브랜치 | `develop` (관리자 검사 결과 관리 · 마이페이지 머지 후) |
| 참고 문서 | UI 설계서, REST API 설계서, Entity 설계서, React 컴포넌트 설계서 |

프론트(React) · 백엔드(Spring Boot) · DB(MariaDB)를 실제로 연결한 상태에서 사용자 화면과 관리자 화면의 전체 흐름을 확인한다.
단위 테스트로 확인하기 어려운 **화면 이동, 토큰 처리, 두 화면 사이의 데이터 연동**을 중심으로 본다.

- 결과 칸은 `✅ 통과` / `❌ 실패` / `➖ 해당 없음`으로 적고, 실패하면 6장 기록표에 내용을 남긴다
- 문구는 UI 설계서 2.4 규칙(화면 문구 끝 마침표 없음)을 같이 확인한다
- 대시보드 숫자는 테스트 중에 계속 바뀌므로 고정값 대신 **증가·감소 여부**로 확인한다
