## 📌 안내사항

현재 backend와 frontend 폴더에 포함되어 있는 파일 및 프로젝트는 프로젝트 초기 구성을 위한 임시 파일입니다.

추후 실제 프로젝트 개발을 진행하면서 프로젝트 목적과 요구사항에 맞게 수정하여 사용할 예정입니다.

## Backend
현재 backend 폴더의 파일은 임시 구성입니다.
실제 백엔드 프로젝트에 맞게 필요한 파일과 폴더를 구성할 예정입니다.
필요하지 않은 파일은 삭제하거나 수정하여 사용합니다.
## Frontend
현재 student_react_first 프로젝트는 임시로 추가되어 있습니다.
실제 프론트엔드 개발 환경과 프로젝트 구조에 맞게 수정하여 사용합니다.
필요에 따라 기존 파일을 삭제하거나 새로운 파일 및 폴더를 추가합니다.

※ 현재 backend와 frontend 내부의 파일은 최종 프로젝트 구조가 아니며, 개발 과정에서 필요에 따라 자유롭게 삭제 및 수정하여 사용할 예정입니다.
